# RideableAPI

Контент-пак для [VoxelCore](https://github.com/MihailRis/voxelcore)

Лёгкий, управляемый событиями API для посадки и высадки игроков на сущности или сиденья.  
Разработан для однопользовательских контент-паков, в планах — поддержка многопользовательской игры.

*Примечание: README написано с помощью ИИ.*

---

## Возможности

- Простой реестр для игроков, которые на чём-то сидят
- Открепление от сущности с автоматическим вызовом коллбеков
- Система событий (`rideable_api:on_mount`, `rideable_api:on_unmount`)

В первую очередь, решает проблему, когда есть лодки, стулья, машины из разных модов с разной системой посадки,
и если не будет общего реестра "сидящих" игроков, плавная пересадка с лодки в машину/стул невозможна.

---

## Установка

1. Скачайте контент-пак.
2. Поместите папку в вашу директорию `content/`.

---

## Для игроков

Этот пак сам по себе не добавляет никаких видимых предметов или механик.  
Это **библиотека**, которую другие контент-паки используют, чтобы позволить игрокам садиться на сущности или управлять ими (лодки, лошади, стулья и т.д.).
