# RideableAPI - Документация для разработчиков

**Версия движка:** VoxelCore 0.31.4
Этот документ описывает, как использовать RideableAPI в вашем контент-паке.

---

## Обзор

RideableAPI предоставляет простой реестр для посадки и высадки игроков на сущности или сиденья. 
Он не обрабатывает физику, управление камерой или движение — это ответственность контент-пака, который использует этот API.

Если вы новичок в разработке контент-паков или предпочитаете пошаговое руководство,
начните с [Туториала](./tutorial.md).

---

## Подключение

Чтобы использовать RideableAPI в вашем контент-паке:

1. Скопируйте файл `typings/local/mount.lua` в ваш проект (для аннотаций типов).
2. Подключите API в вашем коде:

```lua
---@type rideable_api
local rideable_api = require("rideable_api:mount")
```


## Справочник API

### `rideable_api.mount(pid, entity_uid, seat_id, on_unmount)`

Сажает игрока на сущность или сиденье.

- Если игрок уже сидит где-то, он сначала будет высажен.
- Генерирует событие `rideable_api:on_mount`.

**Параметры:**

| Имя | Тип | Описание |
| :--- | :--- | :--- |
| `pid` | `integer` | ID игрока |
| `entity_uid` | `integer or nil` | UID сущности (опционально, для справки) |
| `seat_id` | `any or nil` | Идентификатор сиденья (опционально, для поддержки нескольких мест) |
| `on_unmount` | `function or nil` | Коллбэк, вызываемый при высадке: `fun(pid, entity_uid, seat_id)` |

**Возвращает:** `boolean` — `true` в случае успеха, `false` в противном случае.

---

### `rideable_api.unmount(pid)`

Высаживает игрока.

- Вызывает сохранённый коллбэк `on_unmount` (если он был передан при посадке).
- Генерирует событие `rideable_api:on_unmount`.

**Параметры:**

| Имя | Тип | Описание |
| :--- | :--- | :--- |
| `pid` | `integer` | ID игрока |

**Возвращает:** `boolean` — `true` если игрок был на чём-то и высажен, `false` в противном случае.

---

### `rideable_api.is_mounted(pid)`

Проверяет, сидит ли игрок на чём-то.

**Параметры:**

| Имя | Тип | Описание |
| :--- | :--- | :--- |
| `pid` | `integer` | ID игрока |

**Возвращает:** `boolean`

---

### `rideable_api.get_mount_data(pid)`

Возвращает данные о том, где сидит игрок.

**Параметры:**

| Имя | Тип | Описание |
| :--- | :--- | :--- |
| `pid` | `integer` | ID игрока |

**Возвращает:** `table|nil` — Таблица с полями `entity_uid` и `seat_id`, или `nil`, если игрок нигде не сидит.

---

### `rideable_api.get_mount_entity(pid)`

Возвращает UID сущности, на которой сидит игрок (если есть).

**Параметры:**

| Имя | Тип | Описание |
| :--- | :--- | :--- |
| `pid` | `integer` | ID игрока |

**Возвращает:** `integer|nil` — UID сущности или `nil`, если игрок не сидит на сущности.

---

## События

API генерирует следующие события через библиотеку `events`:

| Событие | Параметры | Описание |
| :--- | :--- | :--- |
| `rideable_api:on_mount` | `pid, entity_uid, seat_id` | Вызывается после посадки игрока |
| `rideable_api:on_unmount` | `pid, entity_uid, seat_id` | Вызывается после высадки игрока |

**Пример:**

```lua
events.on("rideable_api:on_mount", function(pid, entity_uid, seat_id)
    print("Игрок " .. pid .. " сел на " .. entity_uid)
end)
```
